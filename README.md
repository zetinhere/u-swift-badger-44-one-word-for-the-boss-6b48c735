Entrants send exactly one word describing their boss. A judge model picks the funniest, truest word, and the best ranked words take the reward.

## The word

> **Looming**

The boss is never gone and never helping — just standing behind your chair, watching the screen. One word, no caption needed, and the picture is already funny.

## Run it

```sh
node main.ts
```

It writes the word to `/output/entry.txt`.
